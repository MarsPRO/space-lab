# Изменения Space Lab

## 1.2.0

- Стили переведены на SCSS и перенесены в `src/assets/styles/`; параметры оформления вынесены в отдельный файл конфигурации.
- Добавлена тема оформления `default` и место для её выбора в настройках: «По умолчанию» / «Default».
- В настройках сохраняется предпочтительный режим: светлый, тёмный или системный. Системный режим реагирует на изменение темы ОС.
- Переключатель справа меняет текущий режим, не изменяя сохранённую настройку.
- Оформление кода в документации и на площадке унифицировано: светло-серый фон в светлом режиме и тёмный фон в тёмном.
- Исправлена ленивая загрузка подсветки кода в Markdown и панели исходного кода при локальной разработке.
- Добавлены проверки настроек оформления, конфигурации SCSS и браузерные проверки dev и статической сборки.

## 1.1.0

- Добавлена команда `space-lab init` для создания конфигурации проекта из готового шаблона без перезаписи существующего файла.
- Добавлены базовые проверки CLI, runtime, маршрутов и локализации, доступные через `npm test`.
- Сборка и тесты подключены к GitHub Actions.
- Обновлено описание npm-пакета.

## 1.0.2

- Обновлены описание возможностей, быстрый старт и справка по CLI в README.
- Исправлены ссылки на лицензию для страницы пакета в npm.
- Инструкция установки включена в состав npm-пакета.
- Добавлен готовый шаблон конфигурации и команда его копирования без перезаписи существующего файла.

## 1.0.1

- Настроена автоматическая публикация пакета в npm при выпуске релизов на GitHub.
- История изменений включена в состав npm-пакета.

## 1.0.0

- Первая версия Space Lab.
