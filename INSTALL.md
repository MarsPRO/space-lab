# Установка Space Lab

Space Lab распространяется в виде npm-пакета и подключается к существующему проекту как зависимость для разработки.

## Системные требования

Перед установкой убедитесь, что окружение соответствует следующим требованиям:

| Компонент | Поддерживаемые версии |
| --- | --- |
| Node.js | 22.12.0+ (ветка 22), 24.x, 26.x |
| npm | 10.0.0 и выше |
| React | 18.3.1+ (ветка 18), 19.x |
| React DOM | 18.3.1+ (ветка 18), 19.x |

При наличии совместимых версий React и React DOM их переустановка не требуется.

## Установка

Выполните команду в корневом каталоге проекта:

```bash
npm install --save-dev @marspro/space-lab
```

## Проверка установки

Для проверки установленной версии выполните:

```bash
npx space-lab --version
```

Для просмотра доступных команд:

```bash
npx space-lab --help
```

## Альтернативная установка

Space Lab также поддерживает установку из локального npm-архива (`.tgz`).

```bash
npm install --save-dev ./path/to/package.tgz
```

Укажите фактический путь к архиву пакета.

При использовании локального архива обеспечьте его доступность при последующих установках зависимостей.

## Следующие шаги

После успешной установки перейдите к настройке Space Lab.

Установка пакета не выполняет автоматическую инициализацию или настройку проекта.
